# 阅读样式试改

用户希望参考 React 文档的整体阅读感受，先看本地效果，不满意则回退。试改经用户 review 后，于 2026-10-15 获得提交、发布与部署授权，纳入 v0.1.2。

## 基线与恢复

- 试改前工作区干净，基线提交为 `7f2fc01`，包含之前的标题和轻量复制按钮调整。
- 原布局文件备份在 `.logs/reading-trial-baseline/GuideLayout.astro`，提交号保存在同目录 `commit.txt`。
- 新视觉集中在 `src/styles/reading-trial.css`；`GuideLayout.astro` 仅增加它的 import 和 stylesheet link。后续目录交互也修改了 global.css 和阅读脚本；正文未修改。
- 仅回退视觉可以移除这两处引用后重新构建；完整回退需包含下述目录交互改动。若以后又有其他修改，先核对差异，不用全仓 reset 覆盖后续工作。

## 试改内容

统一中文无衬线字体、400 正文字重、段落行距与引言层级；调整正文、标题、列表及代码之间的留白。代码块改为轻边框与圆角，保留 16px 字号和既有复制图标，并保持语言标签与图标居中对齐。

侧栏采用柔和底色与单一浅紫选中背景，去掉重复的章节箭头；进入小节后仅小节显示选中背景，保留当前章文字提示。目录结构、手机推移方式、紫色主题及阅读功能保留。

## 验证范围

- 类型检查无错误，静态构建成功；125 篇、16,238 个原文块及站内目标检查通过。
- 浏览器核查正文实际使用 Microsoft YaHei 和 Segoe UI；检查代码标签/图标中心、章节和小节选中态。
- 桌面、深色、390×844 窄屏与项目配置表格无整页横向溢出；手机侧栏仍为 260px 推移。
- 本轮改进源于本地视觉试版，不是 React 整站复刻，不包含新教学卡片、练习或改写正文。窄屏为浏览器模拟，不是真机测试。

本地入口：<http://127.0.0.1:4323/typescript/array/>。

## 目录交互追加调整
分组标题加深为正文色；所有带二级标题的章节提供独立常驻展开按钮，正文链接继续负责跳转。小节使用渲染器生成的真实锚点。该交互涉及 SidebarNav、ArticleOutline、reader.ts 与 outlines.ts；完整回退试版时也需核对这些文件相对基线的差异，不能只移除 CSS。

## v0.1.2 最终样式
章节 16px、小节 15px，分组标题 17px/600；普通目录为深灰，紫色仅用于选中与悬停。箭头与文字拉开间距，收起状态使用独立 class，避免旧主题将其误判为选中。移除返回顶部按钮及事件逻辑。截图文件保留试改过程；最终截图为 no-back-to-top.jpg。
