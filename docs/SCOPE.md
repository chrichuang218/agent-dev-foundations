- 仓库名称：`agent-dev-foundations`。
- 网站标题：Agent Dev Foundations。
- 面向后端程序员，补齐 Agent 开发所需的 Web 与 TypeScript 基础知识；当前不宣称已提供完整 Agent 实践教程。
- 本地仓库：`D:\Develop\github\agent-dev-foundations`。
- 内容同时包含 HTML、JavaScript、ES6、TypeScript 和项目配置，名称调整不缩减内容范围。

## 目标优先级
1. 自己阅读其他 TS 项目时，能按目录查阅知识，反复理解并掌握。
2. UI 好看，参考 https://diwang.info/how-claude-code-works/#/ 。
3. 希望后续开源并获得 Star；这是次要目标，不作为第一版功能验收条件。

## 产品定位与查询方式
- 产品是按目录浏览的编程知识参考站，不是练习或课程训练平台。
- 用户遇到不认识的代码时，先向外部 AI 询问概念名称，再到网站对应目录查阅。
- 第一版无需内置 AI 解释器、代码片段识别或练习判题功能。
- HTML、JS、ES6、TS 放在同一个站，目录分区，相关知识互相链接。

## UI 方向
- 沿用用户指定参考站的 UI 方向，不另起一套风格。
- 直接使用字节一致的 `docsify-themeable@0.9.0` 主题 CSS，并提取原站 `index.html` 的样式；以实际页面和源码确认布局、交互。
- 分页与复制采用原版插件的静态 CSS 和 DOM；保留中文可访问性反馈、Clipboard API 和键盘焦点，不加载 Docsify 插件运行时或增加依赖。
- 保留用户明确要求的可读性适配：正文 18px、代码 16px、桌面侧栏 300px；手机侧栏按参考站使用 260px，正文上限仍为主题的 `55em`。不宣称与参考站像素相等。
- 首页、分区总览采用原生标题、表格与列表。站内仍使用静态独立 URL；不引入 Docsify 运行时或客户端 Markdown 渲染。
- 移动端与桌面共用一个侧栏，展开时推移正文，按钮保持汉堡图标。点击按钮、侧栏外正文或 Escape 收起；文章、搜索结果与小节跳转时收起，搜索输入及目录折叠操作保持展开。隐藏侧栏和展开目录后的正文分别退出焦点顺序；不增加滑动手势。依据见 [手机侧栏记录](reference/mobile-sidebar.md)。

## 阅读体验与验收要求
- 分组章节目录、当前章节/小节单一定位条、页内锚点及可点击小节标题。侧栏按需跟随当前 H2，用户正在侧栏操作时不抢滚动。
- 前后篇按全部文章顺序跨分区连续导航，保留原版分页箭头、标题、分组副标题和悬停效果；普通跳篇回正文顶部，历史返回恢复浏览器位置。
- 复制成功/失败使用原版弹出提示，1 秒复位；滚动超过 300px 显示返回顶部按钮，并支持减少动态效果。已移除的进度条、页尾“关于”和噪声卡片不恢复。
- 独立静态文章 URL 可直接打开和刷新；窄屏侧栏推移正文，目录、代码和表格可独立滚动；支持基础键盘操作与可见焦点。
- 全部纳入正文及集中来源登记均须实际存在；对上游空节补充有来源依据的内容，不能留下占位文章。文章标题后直接进入正文，不展示速查、阅读提示或自动追加的相关知识卡片。
- 内容检查核对所有来源文件与哈希、逐章目录及生成正文；视觉与交互通过浏览器检查代表性长文、密集代码和表格页面。
- 本地搜索须覆盖全部文章及 H2/H3 小节；支持多词匹配、摘要高亮、小节定位和显式清空，搜索期间保留目录。首次非空查询按需加载同站索引，无外部搜索服务；索引完整性检查纳入 `npm run verify`，实际入口数量见生成的机器证据。浅色/深色偏好仅存于本地浏览器。
- 内置 AI、代码识别、练习判题、账号、云同步、学习打卡、精简目录按钮和额外生态教程均不属于本轮；这不排除完整 HTML / ES6 原文中的相关示例。
