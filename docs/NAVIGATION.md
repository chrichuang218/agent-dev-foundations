# 目录与阅读交互

更新日期：2026-10-13。当前目录采用指定参考站的结构；旧“章节 / 本页”标签方案已替代。

## 当前结构

侧栏由共用 `SidebarNav.astro` 生成。名称、搜索和目录在同一个全高侧栏内滚动，没有额外固定目录标题、顶部导航或目录标签。

1. 名称链接返回首页；搜索框位于名称下方。
2. 普通列表链接提供首页以及 HTML、JavaScript、ES6、TypeScript 四个分区入口。6 篇项目配置放在 TypeScript 的最后一组“项目配置”，TypeScript 共 33 篇。
3. 当前分区的主题组和章节嵌在该顶层节点内，不追加到全部入口之后；其余分区保持独立。当前顶层链接可折叠/展开所属列表，非当前分区链接进入相应总览。组名不是折叠控件。
4. 章节显示分区内连续序号与短标题，完整章名保留在链接 `title` 和文章 H1；使用原主题的右侧定位边线。正文尚未进入 H2 时标记章节；进入 H2 后仅标记小节，章节保留文字高亮；折叠小节后边线回到章节。
5. 只有当前文章下方显示正文 H2，H3 不展示；点击当前文章链接切换其小节目录折叠状态，其余章节链接正常导航。

没有分区的首页和关于页显示四个分区入口。侧栏按分区及桌面/手机分别记住本会话的滚动位置；跳章或刷新时恢复，当前章不可见时只调整侧栏使其可见，不移动正文。手机目录打开后才恢复位置。首页及分区总览使用文档标题、表格与列表，文章路径仍为 `/typescript/generics/`、`/html/form/`、`/es6/async/` 等静态 URL。配置文章继续使用 `/config/*/`，打开时归属 TypeScript 目录；旧 `/config/` 总览跳转到 `/typescript/#project-config`。本轮不增加精简目录按钮。

正文滚动时，仅在当前 H2 链接超出侧栏可视区时调整侧栏；鼠标停留在侧栏或键盘焦点位于侧栏时暂停这种自动跟随，避免打断查阅。

## 搜索、主题与键盘操作

- 搜索索引由 `src/pages/search.json.ts` 在构建时生成，字段为 `title`、`url`、`section`、`body`，包含全部文章及 H2/H3 小节入口；小节结果直接指向标题锚点。索引大小和入口数量随内容重建，以本轮构建后的机器证据为准。
- 每次页面加载后的首次非空搜索按需请求同站索引；150ms 防抖，本页复用。多个关键词按空白分隔，所有词均须命中标题或正文，标题命中优先；最多显示 10 条，正文摘录用 `em.search-keyword` 高亮命中词。
- 搜索结果出现时仍保留目录。提供显式清空按钮，清空后焦点回输入框；加载失败和无结果有明确状态。输入框保留原站满宽 flex 布局和主题色聚焦光晕。
- 圆形主题按钮切换浅色/深色；偏好保存在浏览器 `localStorage.theme`，不传到服务器。
- 桌面和手机共用一个侧栏。桌面宽 300px；手机宽 260px，展开时沿用原主题 `body.close` 将侧栏、按钮和正文一起向右推移，没有灰色遮罩、滚动锁定或独立 X 关闭按钮。展开后按钮仍为三条横线，透明点击区覆盖右侧被推开的正文，点击即可收起。
- 手机目录点击文章、搜索结果或小节链接后收起；同页小节更新锚点并聚焦正文标题。搜索输入、分区折叠和当前章的小节折叠不会收起目录。正文 H2/H3 的整段标题文字可点击定位。
- Escape 收起手机目录并将焦点返回菜单按钮；收起的侧栏退出键盘焦点顺序，手机目录展开时正文退出焦点顺序。保留跳到正文、可见键盘焦点与减少动态效果支持；未增加触摸滑动手势。

## 分页、复制与返回顶部

- 前后篇按全站文章顺序计算，跨主题组、跨分区连续导航。标题与侧栏编号及短名一致；同分区副标题显示组名，跨分区显示“分区 · 组名”。不再限制在当前分区内。
- 分页使用 `docsify-pagination@2.10.1` 的真实 DOM、SVG 折线和注入 CSS。两项同时出现时，前一项标题默认透明度 `.3`，悬停过渡 200ms 到 `1` 并加下划线；标签与副标题按原规则呈现。普通链接跳篇从正文顶部开始，浏览器历史返回保留位置恢复。
- 复制使用 `docsify-copy-code@3.0.2` 的按钮层级与弹出提示 CSS，实际复制由 Clipboard API 完成。中文成功/失败提示与读屏播报在 1 秒后复位，按钮标签不被替换，不强制移走键盘焦点。
- 返回顶部沿用参考站圆形按钮样式，正文滚动超过 300px 后显示。点击平滑回顶；启用减少动态效果时直接定位。

源码依据见 [分页记录](reference/pagination-notes.md) 和 [复制记录](reference/copy-notes.md)。这里只复用静态样式与结构，没有加载插件 JavaScript 或新增依赖。

## 页面信息

文章标题后直接展示完整正文，不展示开头的“速查”和“阅读提示”。已有速查、勘误和版本注记保留在本地编辑数据中，新章节无需补写速查；`summary` 继续用于搜索与页面描述。署名、来源版本、许可和全部文章的来源登记集中在 `/about/`，文章尾部只保留前后篇；不显示关于入口。没有重复口号、通用边界说明或自动追加的来源/关联卡片；来源记录继续保存。

## 与参考站的边界

原主题 CSS 字节不变，原站页面样式已提取为本地文件。静态文章路由、四分区内容和构建时 Shiki 高亮属于本站适配。正文 18px、代码 16px、桌面侧栏 300px 保留用户明确的可读性要求，手机侧栏按参考站恢复为 260px。按本轮要求，展开图标保留汉堡，不旋成 X；另保留键盘操作与目录折叠期间不收起的适配。不宣称像素一致。详细取证见 [手机侧栏记录](reference/mobile-sidebar.md) 和 [UI-REFERENCE.md](UI-REFERENCE.md)。
