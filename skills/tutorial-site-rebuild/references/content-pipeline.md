# 完整教程内容管线

## 三种真值，各有归属

| 层 | 保存什么 | 更新规则 |
| --- | --- | --- |
| 来源锁与快照 | 仓库、固定 commit、许可依据、文件路径及哈希、原始字节 | 更新上游时审阅差异后显式更换；普通导入不改 |
| 本地编辑与映射 | 稳定 ID、分区/分组/顺序、摘要、资源映射、补充/勘误 | 人工维护；上游同步不得覆盖 |
| 生成物 | 文章目录、导航、搜索、覆盖表、静态 HTML、公共资源副本 | 从前两层生成；检查模式发现不一致应报错，不自动接受新来源 |

可以沿用项目既有数据结构。示意字段不是新的必选框架：

```json
{
  "id": "config/tsconfig",
  "path": "/config/tsconfig/",
  "section": "typescript",
  "group": "项目配置",
  "sourceFile": "content/upstream/typescript/docs/tsconfig.json.md",
  "summary": "来源支持的简短描述"
}
```

ID、URL、来源位置和目录归属不是同一字段。将配置移到 TypeScript 下不需要改 `/config/tsconfig/`。导航、搜索和前后篇消费同一个有序文章集合；源版本和哈希只设一个权威账本。

## 逐文件清点

扫描真实仓库目录，而不是只读 `_sidebar.md`、`chapters.yml` 或在线菜单。列出全部候选正文与元资料，逐项登记来源文件、纳入/排除/合并、稳定路径、理由、整理状态、验证状态。

- 全部收录：包括未列菜单的正文、附录和历史提案。作者前言/鸣谢若是教程章也应按范围处理，不能仅凭文件名静默丢弃。
- README、部署说明、书籍购买页等非知识章可以只归档，但要登记理由；若用户要求原站全部页面，则这些页面也在对账范围。
- 范围内混合章需要截取时，记录完整小节的起止依据；不要把删到摘要叫完整正文。
- 图片/音视频/下载文件区分真实呈现资源、代码块内示例 URL 和普通参考外链，避免下载或执行代码示例的资源。
- 在线来源即使返回 200，也要验证文章标题与正文；回退到首页时用固定源码链接，本站正文照常完整提供。

Windows 上 `core.autocrlf` 会改变工作树字节。需要原始快照时可从固定 commit 的 Git blob 取字节；哈希约束要覆盖实际交付文件，并用适当 `.gitattributes` 防止再次改写。不要把 CRLF 转换误报为上游内容变更。

## 许可与归属

分开核查 UI 代码、主题/插件、教程文字、图片/字体。检查 README、实际 LICENSE、package 元数据、在线声明及逐素材署名；GitHub license API 404 只说明未识别，不等于没有许可。

遇到声明冲突或拼写异常，保存原文、固定版本、核查日期、采用依据和未解决边界。核对整篇教程声明是否覆盖该来源及素材；不要用 UI 的 MIT 覆盖正文，也不要把某一次仓库的版本结论推广到其他仓库。外部配图需要自己的署名链；无法确认可复用时记录具体依据，采用链接或独立制作等可行方式并报告缺口，不伪造完整性。

使用同一来源的替代 CDN 时核对素材身份并记录原 URL、取得 URL、哈希与许可；保持 TLS 验证。许可与来源可按用户当前要求集中展示，撤掉正文来源卡片不等于删除法定署名与维护记录。

## Markdown 转换的高风险位置

- **标题**：只移除交付模板重复的文章 H1，保留全部正文标题；内联代码、重复标题、中文/特殊字符有稳定 slug。目录与搜索索引直接消费实际渲染 ID，避免各自另算一套。
- **链接**：用每篇真实来源基址解释相对地址；映射本地已收录文章，保留查询/hash。未收录目标按明确规则保留外链。不能把“非 JS”一律当作 TS。
- **标签示例**：HTML 教程的 `<script>`、`<a>` 可能是标题文字；代码块中的 form/iframe/script 只能显示，不能运行。不要为一张真实示例表格全局开启未过滤 HTML。
- **特殊 HTML**：先从实际源文盘点需要的语法。对本例这样的表格与上标，采用受控元素/属性白名单，其他原始 HTML 转义；未知受控结构明确报错，避免静默丢正文。
- **正文比对**：代码块比较原始代码，普通段落比较渲染可见文字；合法表格/上标不能要求其标签字符串出现在正文。图片另核对来源映射、哈希、alt、尺寸和加载，避免把图片 alt 当作消失的段落。
- **资源**：真实图片保存本地并映射原引用，宽高/比例和窄屏约束一起处理；正文正常阅读不依赖上游在线服务。
- **搜索**：由渲染正文提取分段，排除复制按钮和反馈文字；覆盖每篇入口与约定级别小节，确认唯一目标、分区、查询跳转和空结果。

## 内容与更新验收

自动对账应能发现：来源清单漏文件、同 ID 重复、纳入章无页面、空正文/空节、正文或代码删减、旧目录生成物、无效锚点、缺图片、错父分区、失效旧 URL、被覆盖的本地编辑。已有检查优先扩展，不要求所有项目采用固定脚本名或依赖。

重跑导入并检查生成物一致；新增章节不能靠补一份首页清单就算完成。正文完整性与文章示例语义分开：历史提案、伪代码、预期错误和宿主环境示例未实际运行时明确说明，不能仅凭换 UI 宣称内容已更新到最新标准。
